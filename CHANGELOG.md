# Changelog

Notable changes to the plugins in this marketplace, newest first. Each plugin has its own version, in its `.claude-plugin/plugin.json`.

## pr-overview

### 0.1.1 (2026-10-21)

- Changing **Refresh interval (minutes)** in `/config` takes effect at once in an installed copy too. The change's owner is named with its marketplace (`pr-overview@pt-mods`), and only the bare name was recognised.

### 0.1.0 (2026-10-20)

- `/pr-overview` opens a pane of the open PRs in the session's repo that you're involved in: you opened it, commented, reviewed, were asked to review it by name, were assigned or @-mentioned, or pushed commits to it. Newest activity first.
- `●` marks a PR with activity since you last opened it from the list. Your own comments, reviews and pushes don't mark it. The marks are shared by every session; a closed or merged PR's entry is dropped, and other repos' entries after 90 days.
- Each row shows CI (`✓` `✗` `…`), a merge conflict, and how long ago the PR was updated. Drafts are dim.
- Tab moves, Enter opens the PR with `gh pr view --web` (falling back to the system's opener, Windows included), `r` refreshes, Escape closes.
- Refreshes every 30 minutes while open: **Refresh interval (minutes)** in `/config`.

## sidebar

### 0.6.2 (2026-10-21)

- Changing **Billing discount (%)** or **GBP rate (£)** in `/config` shows at once in an installed copy too. The change's owner is named with its marketplace (`sidebar@pt-mods`), and only the bare name was recognised. `/gbp` uses the same check.

### 0.6.1 (2026-10-20)

- `/gbp` in `claude -p` says plainly that the setting can't be saved there, instead of passing on Claude Code's error. (#6, kizzsandhu)
- `/gbp` finds its setting under `claude --plugin-dir`, where the setting's owner is `sidebar@inline`. (#6, kizzsandhu)

### 0.6.0 (2026-10-19)

- In an Orca terminal, the status line feeds hand their input on to Orca's status line script, so Orca's usage display keeps working without naming Orca's script, which Orca would replace. (#5, kizzsandhu)
- `statusline-feed.sh` takes `-Then` too, as the PowerShell feed does. (#5, kizzsandhu)
- Windows: `-Then` no longer gets a byte order mark under the UTF-8 code page. (#5, kizzsandhu)
- Tests for both feeds, run by GitHub on Linux, macOS and Windows whenever a feed changes. (#5, kizzsandhu)

### 0.5.0 (2026-10-15)

- Optional £ beside $ costs: the session cost, the list price and the cache chip. Off by default; turn it on with **GBP rate (£)** in `/config`, or switch it with `/gbp`. The Cost section shows the rate in use. (#4, kizzsandhu)
- With £ on, the sidebar fetches the European Central Bank's daily USD to GBP rate from `api.frankfurter.dev`: at most about 4 requests a day, shared by all sessions. Nothing is fetched while it's off. If a fetch fails, the last saved rate is kept.

### 0.4.0 (2026-10-14)

- `statusline-feed.ps1`, a status line feed for Windows that needs neither bash nor `jq`. `-Then <program>` passes the same input on to another status line program, so an existing status line keeps working. (#3, kizzsandhu)

### 0.3.4 (2026-10-13)

- Windows: the home folder falls back to `USERPROFILE` when `HOME` isn't set, so the pricing file and status line feed are found and paths are shortened to `~`. (#2, kizzsandhu)
- Windows: the repo name is shown instead of the repo's full `C:\...` path. (#2, kizzsandhu)
- README: the example Opus 5.5 pricing row now has Opus 5.5's prices. (#2, kizzsandhu)

### 0.3.3 (2026-10-13)

- Windows: `/open-pr`, the open-PR button and `ctrl+x o` now open the PR in the browser. (#1, kizzsandhu)

### 0.3.2 (2026-10-13)

- The sidebar fills in again within a second or so after `/clear` or `/new`, instead of staying blank until the next turn.

### 0.3.1 (2026-10-13)

- The elapsed time no longer shows as thousands of days after a resume, `/clear` or `/new`. With the status line feed, it includes time before a resume.

### 0.3.0 (2026-10-09)

- The CI section shows merge conflicts with the base in red, with a toast when they first appear, and re-checks every 5 minutes once CI has finished.

### 0.2.0 (2026-10-09)

- A billing discount setting, **Billing discount (%)** in `/config`, 9% by default. It's taken off the session cost and the cache rebuild cost, both marked `*`. A Cost section shows the discount, the session cost at list price, and how to change it.

### 0.1.1 (2026-10-08)

- A `/model` switch shows in the sidebar straight away.

### 0.1.0 (2026-10-07)

- First release: a pane docked beside the fullscreen transcript with Model, Session, Workspace, CI and Tasks sections, the prompt-cache chip, and the `/sidebar`, `/ci-refresh` and `/open-pr` commands.
- Optional extras: `statusline-feed.sh` for fast mode, the real cache TTL and added dirs; a pricing file for the cache rebuild cost in dollars.
